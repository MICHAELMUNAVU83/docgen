# Docgen

Turns pasted text or uploaded files (`.md`, `.txt`, `.docx`, `.pdf`) into
documents in the official GS1 house style, as Word (`.docx`) and PDF, using
the GS1 Basic, Advanced and Letterhead templates.

See `project.md` for the architecture and `tasks.md` for progress.

## Requirements

- Elixir 1.17+ and PostgreSQL (for the document history)
- **LibreOffice** for PDF export — `brew install --cask libreoffice`
  (on macOS, open LibreOffice.app once so Gatekeeper allows headless runs)
- **Poppler** for PDF import and TOC page numbers — `brew install poppler`
- **Fonts**: Verdana (ships with macOS; `ttf-mscorefonts-installer` on
  Debian/Ubuntu). PDFs fall back to substitute fonts without it.

The app logs a warning at boot for any missing tool; everything else keeps
working.

## Setup

```sh
mix setup          # deps, database, assets
mix phx.server     # http://localhost:4000
```

## Usage

**Web UI** — `/`: paste or upload content, pick a template, fill in the
metadata, watch the live preview, download `.docx` or PDF. Uploaded Word and
PDF files are converted to editable Markdown. `/history` lists generated
documents.

**Command line**:

```sh
mix docgen.render notes.md                       # → notes.docx (GS1 Basic)
mix docgen.render notes.md --pdf                 # also notes.pdf
mix docgen.render spec.md --template advanced \
  --title "Supplier Guide" --doc-type Guideline --cover retail
mix docgen.render report.docx                    # → report-gs1.docx
```

**From Elixir**:

```elixir
doc = Docgen.parse(markdown, :markdown, template: :advanced, meta: %{title: "Spec"})
{:ok, docx} = Docgen.to_docx(doc)
{:ok, pdf} = Docgen.to_pdf(doc)
{:ok, doc} = Docgen.ingest(File.read!("report.docx"), :docx)
```

### Markdown extensions

- `> **Note:** …` / `> **Important:** …` — GS1 note styles
- `Table: Caption` directly before or after a table — numbered table caption
- `![Caption](image)` — images keep their caption as a numbered figure caption
- Front matter `title:` / `subtitle:` fills the metadata

### Templates

| Template | Metadata |
|---|---|
| GS1 Basic | title, subtitle |
| GS1 Advanced | name, type, description, version, status, date, cover graphic (corporate visual, none, or an industry icon); cover page, summary, disclaimer and table of contents come from the template |
| GS1 Letterhead | sender, title, address, recipient, date, subject, salutation, closing; option to hide graphics for pre-printed paper |

## Configuration

Environment variables (read in `config/runtime.exs`):

| Variable | Purpose |
|---|---|
| `DOCGEN_ORG_NAME` | Member Organisation name, replacing "GS1 AISBL" in headers/footers |
| `DOCGEN_ORG_WEBSITE` | replaces `www.gs1.org` |
| `DOCGEN_ORG_ADDRESS` | Letterhead footer address, lines separated by `\|` |
| `DOCGEN_LOGO_PATH` | PNG/JPEG replacing the GS1 logo in all templates |
| `DOCGEN_PDF_CONCURRENCY` | parallel LibreOffice conversions (default 2) |

Tool paths can be overridden with `config :docgen, :tools, soffice: "/path"`.

## Tests

```sh
mix test                          # needs PostgreSQL
mix test --include libreoffice    # also runs real LibreOffice conversions
```

Word and PDF fixtures are generated by the tests (`test/support`), so no
binary fixtures are committed.

## Deployment

The `Dockerfile` builds a release with LibreOffice, poppler and fonts
(Microsoft core fonts for Verdana are included unless built with
`--build-arg INSTALL_MS_FONTS=false`). Check that the builder image tag
exists on Docker Hub before building.

```sh
docker build -t docgen .
docker run -e DATABASE_URL=... -e SECRET_KEY_BASE=... -e PHX_HOST=... docgen /app/bin/migrate
docker run -p 4000:4000 -e DATABASE_URL=... -e SECRET_KEY_BASE=... -e PHX_HOST=... docgen
```

Generated files are held in memory for 30 minutes for download; stale temp
files are swept every 30 minutes.
